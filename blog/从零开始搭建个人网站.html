从零开始搭建个人网站

建站记录 / HTML / CSS / JavaScript

这个网站是我从零开始搭建的个人主页。它现在包含个人介绍、作品集、简历、博客和联系方式，也会继续随着我的学习慢慢完善。

第一步：写出网页内容

我先创建了 HTML 文件。HTML 可以理解成网页的骨架，它负责告诉浏览器：哪里是标题，哪里是段落，哪里是作品，哪里是联系方式。

第二步：调整网页外观

接着我创建了 CSS 文件。CSS 可以理解成网页的外观设置，它负责颜色、字体、间距、按钮和卡片效果。通过 CSS，普通文字可以变成更像正式网站的页面。

第三步：加入简单互动

然后我加入了 JavaScript。JavaScript 可以理解成网页的动作，它让页面能回应我的操作，比如回到顶部、导航高亮、博客展开。

第四步：适配手机

最后，我为手机屏幕做了单独优化。这样同一个网站在电脑和手机上都能保持清楚、舒适，不会因为屏幕变小就挤在一起。
